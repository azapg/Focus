Methodology

Each sample is one live Gateway response to a fictional request in Focus’s desktop or phone-direct format. A case can appear again in another run, model, route or trial.

The rubric checks the action, exact scope, duration and any required Store or habit guidance. An overgrant opens access the rubric forbids or grants more scope or time than the case allows. Other mismatches include conservative decisions and missing guidance.

History off clears prior pause reasons, matching outcomes and ratings. Reasoning default uses the app’s Gateway configuration. Phone direct has no desktop DNS evidence or scoped grants.

Latency is wall-clock time for the sample, including transport retries. P95 uses judged samples. Cost totals include values Gateway reported. The benchmark ends at the proposal, before the app applies a hold or changes DNS.
